## 补充练习题（来自互动组件，正确性未回传，仅供参考复盘）

**Q1.** 某公司的 S3 存储桶因为被设置为公开可读而导致数据泄露。根据责任共担模型，这个安全事件的责任在谁？
✅ 客户，因为存储桶权限配置属于"云中的安全"(Security IN the cloud)

**Q2.** 以下哪一项不属于 AWS 官方列出的云计算六大优势？
✅ 保证100%系统零故障（AWS从不做这种绝对化承诺）

**Q3.** 一家初创公司希望以最低成本运行一个可以随时被中断、对中断不敏感的批处理任务，应该选择哪种 EC2 定价模型？
✅ Spot Instance（竞价实例）

**Q4.** 关于 IAM 最小权限原则，以下哪种做法最符合该原则？
✅ 只授予用户完成当前工作任务所必需的最小权限集合

**Q5.** 一个 EC2 实例需要挂载一块可持久化、只能同时挂载给单个实例使用的块存储卷，应该选择哪个存储服务？
✅ Amazon EBS

**Q6.** 某公司希望多个 AWS 账户的用量汇总在一起计费，以便享受更大的批量折扣，同时集中管理这些账户，应该使用什么功能？
✅ AWS Organizations + Consolidated Billing

**Q7.** 一家企业需要15分钟内的技术支持响应时间，并希望配备专属的技术客户经理(TAM)，应该选择哪个 Support Plan？
✅ Enterprise

### 第二轮
**Q1.** 通过合理选择实例类型、减少闲置资源来降低能耗、提升资源利用效率，最符合 Well-Architected 哪个支柱？ ✅ 可持续性(Sustainability)
**Q2.** 提高容灾能力，即使某个数据中心故障业务也不中断，最直接有效的做法？ ✅ 把资源分布部署在同一Region内的多个AZ
**Q3.** 需要审查过去一周哪个IAM User在什么时间调用了哪些API操作，查看哪个服务日志？ ✅ CloudTrail
**Q4.** 只配了Security Group入站规则(443端口)，没配出站规则，但响应正常，为什么？ ✅ Security Group有状态(Stateful)，出站自动放行
**Q5.** 保存7年审计日志，几乎不访问，取用能接受几小时等待，要求存储成本最低，选哪个S3类别？ ✅ S3 Glacier Deep Archive
**Q6.** Web应用频繁遭受SQL注入和XSS攻击，需要过滤应用层恶意请求，用哪个服务？ ✅ AWS WAF
**Q7.** 运行容器化应用但不想管理任何底层服务器/集群，只关注容器部署运行，用哪种方式？ ✅ AWS Fargate
**Q8.** EC2实例状态变"stopped"时触发Lambda发通知，变"terminated"时触发另一套流程，用哪个服务？ ✅ Amazon EventBridge
**Q9.** 迁移新项目到AWS前，想先估算每月大概费用，用哪个工具？ ✅ AWS Pricing Calculator
**Q10.** 本地500TB历史数据要迁移到S3，网络带宽有限现有网速要传一个多月，用哪个服务？ ✅ AWS Snowball

### 第三轮
**Q1.** 发现恶意IP在扫描端口，要明确封锁该IP所有流量、不影响其他正常访问，怎么做？ ✅ 在子网NACL中添加一条显式Deny该IP的规则
**Q2.** NACL和子网(Subnet)的关联关系，哪项正确？ ✅ 一个NACL可关联多个子网，但一个子网同一时刻只能关联一个NACL
**Q3.** 存储可随时重新生成的图片缩略图，不常访问、丢了也能重建，要求存储成本尽量低，选哪个类别？ ✅ S3 One Zone-IA
**Q4.** 订单服务通过SQS向库存服务发消息，库存服务因部署临时宕机10分钟，这期间消息会怎样？ ✅ 留在队列里，服务恢复后继续消费，不会丢失
**Q5.** 全球员工上传中等大小设计文件到总部S3桶，跨地域上传慢，用哪个服务加速？ ✅ Amazon S3 Transfer Acceleration
**Q6.** VPC中，什么决定一个子网是Public还是Private Subnet？ ✅ 子网路由表里有没有一条指向Internet Gateway的路由
**Q7.** EC2访问S3时为什么推荐绑定IAM Role而不是代码里硬编码Access Key？ ✅ IAM Role提供临时凭证，无需硬编码密钥

### 第四轮
**Q1.** 存储购物车数据，数据量巨大、读写并发极高、结构灵活、延迟要求敏感，选哪种数据库？ ✅ Amazon DynamoDB
**Q2.** IAM策略评估逻辑，哪项正确？ ✅ 默认拒绝所有操作除非明确允许；同时存在拒绝和允许时，拒绝优先
**Q3.** EC2 CPU利用率连续5分钟超80%自动触发Auto Scaling新增实例，这个告警触发机制依赖哪个服务？ ✅ CloudWatch
**Q4.** 任务每天凌晨3点跑一次、每次只需2分钟，其余时间不需要计算资源，最划算的方式？ ✅ 用Lambda，按执行次数和时长计费
**Q5.** 每月AWS费用接近预算80%时想收邮件告警，用哪个工具？ ✅ AWS Budgets
**Q6.** S3静态资源全球用户访问都要回源同一Region导致远程用户加载慢，怎么优化？ ✅ S3前面搭配CloudFront做全球内容分发
**Q7.** 想自动监测账户里的异常登录/可疑API调用等潜在恶意行为并告警，用哪个服务？ ✅ Amazon GuardDuty

### 第五轮
**Q1.** 向客户分享私有S3桶里的合同文件，只能24小时内访问、之后失效，且不能把整桶设公开，怎么做？ ✅ 生成带有效期的预签名URL(Presigned URL)
**Q2.** S3+CloudFront架构中配置Origin Access Control(OAC)的主要目的？ ✅ 防止绕过CloudFront直接用S3原始URL访问
**Q3.** 把订单/客服/广告系统数据汇总，给管理层做跨部门历史销售趋势分析和BI报表，用哪种数据库？ ✅ Amazon Redshift
**Q4.** 网站需要根据URL路径把请求路由到不同后端服务，用哪种负载均衡器？ ✅ Application Load Balancer(ALB)
**Q5.** 注册两个AWS账户，想把各自12个月免费Free Tier额度合并用，可行吗？ ✅ 不可以，每个账户额度独立绑定不能共享合并
**Q6.** 欧洲公司因GDPR必须将用户数据存在欧盟境内，选Region时最应优先考虑什么？ ✅ 延迟、合规/数据主权要求、服务可用性、成本等综合因素
