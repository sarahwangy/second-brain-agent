## 使用建议

出现题数越多的概念，是考试的核心重灾区，优先搞懂。**EC2、S3、Elasticity、IAM、On-Demand/Reserved/Spot这几个定价+计算+存储+权限的基础概念，加起来占了题库里绝大多数的题**，这几个不吃透，考试大概率过不了；后面出现次数个位数的概念，了解个大概、别在这些细节上死磕。

对照Domain权重看：**EC2/S3/RDS/DynamoDB/VPC等具体服务名对应Domain 3（34%权重，占比最高）**；**IAM/Shared Responsibility/加密/合规相关对应Domain 2（30%权重，AIF-C01已经学过大部分）**；**On-Demand/Reserved/Spot/Savings Plans/Support Plans对应Domain 4（12%权重）**；**Elasticity/迁移7个R对应Domain 1（24%权重）**。

## 概念表

| 概念 | 是什么（解释） | 用在什么场景 |
|---|---|---|
| **Amazon EC2**（175题） | AWS的虚拟机服务——按需租用计算资源（CPU/内存），是最基础、最常用的计算服务 | 需要一台"可以自己控制操作系统"的服务器时用，题库里出现频率最高，务必吃透实例类型/定价模式 |
| **Amazon S3**（83题） | 对象存储服务，存文件（图片、视频、备份、静态网站等），按容量+请求次数计费，有多个存储层级（Standard/IA/Glacier等） | 存静态资源、备份、数据湖场景，考试常考存储层级怎么选最省钱 |
| **Elasticity（弹性）**（78题） | 云计算的核心优势之一——资源能根据需求自动增减，不用提前猜容量、也不会因为需求突增而资源不够 | Domain 1"云计算优势"考点的核心词，常跟Auto Scaling一起考 |
| **IAM**（76题） | 身份和访问管理服务，控制"谁能访问什么资源、能做什么操作"，AWS安全的地基 | 几乎每个AWS认证都考，权限最小化原则、用户/组/角色/策略的区别是高频考点 |
| **On-Demand（按需计费）**（46题） | 用多少付多少，没有长期承诺，单价最高但最灵活 | 短期/不确定用量的场景，是默认计费模式，常跟Reserved/Spot对比考"哪种最省钱" |
| **Reserved Instances（预留实例）**（45题） | 承诺用1年或3年，换取比On-Demand便宜很多的单价 | 长期稳定、可预测的工作负载（比如常年运行的数据库），省钱但灵活性低 |
| **Amazon RDS**（42题） | 托管关系型数据库服务（支持MySQL/PostgreSQL/SQL Server等引擎），AWS负责备份/打补丁/故障转移这些运维工作 | 需要关系型数据库又不想自己管理服务器运维时用 |
| **AWS Trusted Advisor**（41题） | 自动检查账户配置，从成本优化/性能/安全/容错/服务限制五个维度给出改进建议 | "怎么发现账户里的问题/优化空间"这类题的标准答案 |
| **Shared Responsibility Model（责任共担模型）**（41题） | AWS负责"云本身的安全"（硬件、基础设施），客户负责"云里面的安全"（数据、配置、访问控制）——这条界限考试必考 | AIF-C01已经学过，直接复用；判断"这个安全问题该AWS管还是客户管"的题目高频出现 |
| **Spot Instances（竞价实例）**（41题） | 用AWS闲置计算容量，价格最便宜（比On-Demand便宜最多90%），但AWS可能随时回收（提前2分钟通知） | 能容忍中断的场景（批处理、测试、可容错的分布式任务），不适合关键业务 |
| **Amazon VPC**（37题） | 在AWS里划出一块属于自己的私有虚拟网络，可以自己定义子网、路由、安全组 | 网络隔离、安全架构设计的基础，Domain 3网络相关题目的核心 |
| **Amazon DynamoDB**（36题） | 全托管NoSQL数据库，按需自动扩展，适合海量数据+低延迟读写场景 | 跟RDS对比考"关系型 vs NoSQL该选哪个"，DynamoDB适合结构简单、高并发的场景 |
| **Amazon GuardDuty**（35题） | 智能威胁检测服务，用机器学习持续监控账户里的可疑活动（异常API调用、恶意IP等） | "怎么自动检测安全威胁"这类题的标准答案，跟Inspector（找漏洞）和WAF（挡攻击）容易混 |
| **AWS WAF**（33题） | Web应用防火墙，在应用层过滤恶意HTTP/HTTPS流量（SQL注入、XSS攻击等） | 保护面向公网的Web应用，常跟AWS Shield（防DDoS）一起考，两者防护层面不同 |
| **AWS Lambda**（32题） | 无服务器计算服务，上传代码，AWS自动运行，不用管服务器，按实际执行时间计费 | "不想管理服务器、按使用付费"的场景，是Serverless架构的核心 |
| **AWS Inspector**（30题） | 自动化安全评估服务，扫描EC2/容器镜像找已知漏洞 | 跟GuardDuty区别：Inspector找"已知漏洞"（偏静态扫描），GuardDuty找"异常行为"（偏实时监控） |
| **Amazon CloudWatch**（29题） | 监控服务，收集指标（CPU使用率等）、设置告警、查看日志 | "怎么监控资源健康状况、设置告警"这类题的标准答案 |
| **Encryption（加密）**（28题） | 数据传输中(in transit)和静止存储(at rest)的加密保护 | AIF-C01已学过，直接复用，常跟KMS一起考 |
| **Amazon ECS/EKS/Fargate**（28题） | 容器编排服务——ECS是AWS自家的容器管理服务，EKS是托管Kubernetes，Fargate是两者都能用的无服务器容器运行方式（不用管底层EC2实例） | 需要跑Docker容器化应用时选择，Fargate常作为"不想管理服务器"的答案出现 |
| **AWS Direct Connect**（28题） | 从企业本地机房到AWS之间拉一条专用物理网络连接，不走公共互联网 | 需要稳定、低延迟、大带宽的混合云连接场景，跟VPN对比考"哪个更适合" |
| **AWS Well-Architected Framework**（28题） | 六大支柱（卓越运营、安全性、可靠性、性能效率、成本优化、可持续性）的架构最佳实践框架 | AIF-C01学过框架名字，CLF-C02会考更具体的支柱内容和评估工具 |
| **AWS CloudTrail**（27题） | 记录AWS账户里所有API调用的操作日志（谁在什么时候做了什么） | 审计追踪的标准答案，常跟AWS Config（记配置状态变化）混淆 |
| **AWS Shield**（26题） | DDoS攻击防护服务，Standard版本免费自动启用，Advanced版本付费提供更强防护+专家支持 | 防范大流量DDoS攻击，跟WAF（防应用层攻击）配合使用但防护层面不同 |
| **Amazon CloudFront**（26题） | CDN内容分发网络，把内容缓存到全球边缘节点，让用户就近访问、加快加载速度 | 加速静态内容分发、降低源站压力的标准方案 |
| **AWS Config**（25题） | 持续跟踪AWS资源配置的变化历史，检查是否符合预设的合规规则 | "配置有没有被意外改动、现在合不合规"这类题的标准答案 |
| **AWS CloudFormation**（25题） | 用代码（模板文件）定义和自动部署AWS基础设施，即Infrastructure as Code | 需要重复、一致地部署同一套基础设施架构时用，避免手动点击控制台出错 |
| **Amazon Aurora**（25题） | AWS自研的高性能关系型数据库，兼容MySQL/PostgreSQL，性能比标准RDS更强 | 需要比标准RDS更高性能/可用性的关系型数据库场景 |
| **Cost Explorer**（23题） | 可视化查看和分析AWS花费趋势的工具，能按服务/时间/标签拆解成本 | "怎么分析/预测AWS花了多少钱"这类题的标准答案 |
| **AWS Organizations**（23题） | 集中管理多个AWS账户（合并账单、统一设置权限边界SCP） | 企业有多个AWS账户（不同部门/环境）需要统一管理时用 |
| **AWS Systems Manager**（22题） | 集中管理/自动化操作EC2和其他资源的运维工具集（补丁管理、远程命令执行等） | 大规模EC2实例的运维自动化场景 |
| **Amazon EBS**（21题） | EC2实例挂载的块存储卷（类似虚拟硬盘），数据持久化，EC2重启数据不丢 | EC2需要持久化存储（数据库文件等）时挂载使用，跟实例存储（临时的）区分 |
| **Availability Zone（可用区）**（21题） | 一个Region内的多个物理隔离的数据中心，AZ之间低延迟连接但故障隔离 | Domain 1全球基础设施考点，"跨AZ部署提升可用性"是常见答案 |
| **Compliance（ISO/SOC/PCI合规）**（20题） | AWS通过的第三方合规认证（ISO 27001、SOC报告、PCI DSS支付卡行业标准等） | 客户想验证AWS基础设施是否符合行业合规要求时查看这些认证 |
| **AWS Budgets**（20题） | 设置预算阈值，花费接近/超过预算时自动发告警 | "怎么防止AWS账单意外超支"这类题的标准答案，跟Cost Explorer（看历史）互补 |
| **Amazon Redshift**（18题） | 全托管数据仓库服务，专门做大规模数据分析/BI查询（列式存储，适合聚合查询） | 需要跑复杂分析查询、构建数据仓库时用，跟RDS（面向事务处理）用途不同 |
| **AWS Artifact**（17题） | 下载AWS合规报告/协议的自助服务门户（本身不做检测，是文档中心） | 需要下载ISO证书、SOC报告这类合规文档时使用 |
| **Savings Plans**（17题） | 承诺一定时长的稳定使用量（不限定具体实例类型），换取比On-Demand低的价格，比Reserved Instances更灵活 | 用量稳定但实例类型/区域可能变化的场景，是Reserved Instances的更灵活替代品 |
| **AWS Support Plans**（17题） | 四档支持计划：Basic（免费）、Developer、Business、Enterprise，响应时间和支持深度依次提升 | Domain 4核心考点，要记住每档大致的价格门槛和适用场景 |
| **Amazon Route 53**（16题） | DNS域名解析服务，也支持健康检查、流量路由策略 | 域名管理、跨区域流量分发/故障转移场景 |
| **AWS Secrets Manager**（15题） | 集中存储和自动轮换密钥/密码/API key等敏感凭证 | 应用需要安全存取数据库密码等敏感信息、又想自动定期轮换时用 |
| **Auto Scaling**（15题） | 根据负载自动增减EC2实例数量，配合Elasticity概念 | 流量有波动的应用，自动应对高峰/低谷，节省成本+保证性能 |
| **Amazon Macie**（14题） | 自动扫描S3数据，用ML检测敏感信息（PII、信用卡号等） | AIF-C01学过，直接复用 |
| **迁移策略"7个R"**（7题） | Rehost/Replatform/Repurchase/Refactor/Retire/Retain/Relocate——七种把工作负载迁移上云的策略 | Domain 1云迁移考点，记住每个R大致代表"改动程度从小到大"这个梯度 |

## 复习优先级建议

**第一优先（题数极高，必须吃透）**：Amazon EC2、Amazon S3、Elasticity、IAM、On-Demand/Reserved/Spot三种计费模式

**第二优先（30-45题，重点覆盖）**：Amazon RDS、AWS Trusted Advisor、Shared Responsibility Model、Amazon VPC、Amazon DynamoDB、GuardDuty、WAF、Lambda

**已经从AIF-C01学过、可以直接复用（不用重新细学）**：Shared Responsibility Model、IAM、Encryption、AWS Well-Architected Framework、Compliance(ISO/SOC/PCI)、AWS Artifact、Amazon Macie

**Domain 3全新的具体服务名（AIF-C01完全没考过，要老实过一遍）**：ECS/EKS/Fargate、Elastic Beanstalk、Aurora、Redshift、Route 53、Direct Connect、Systems Manager、CloudFormation

**Domain 4计费相关（全新，偏背诵）**：On-Demand/Reserved/Spot/Savings Plans四种计费模式的区别、AWS Support Plans四档、Cost Explorer/Budgets两个成本工具的分工

**题数个位数的概念**：了解大概是什么、用在什么场景就够了，不用死记参数细节（比如迁移7个R，知道大致有这么几种策略、大概含义即可，不用背到能默写全部定义）。
